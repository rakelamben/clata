# Stitch Prompt — Kata Feed / Entry Screen

Use the global Clata prompt. Design the first main mobile screen after onboarding: the Kata feed in Bahasa Indonesia. There is no separate Home/index screen.

Top area: compact greeting **Selamat datang**, current package label **Jawa · Mataraman**, and a settings icon with an accessible label.

Main content: a prominent warm card titled **Lanjutkan belajar**, showing the current unit **Unit 1 · Sapaan dan basa-basi**, a small progress indicator, and primary button **Mulai belajar**. Below it show a streak status **Streak 3 hari** with text explanation, then a simple grid/list of actions: **Kata**, **Latihan**, and **Tantangan**. Dialog is accessed inside Latihan.

Use a four-item bottom navigation with labels **Kata**, **Latihan**, **Tantangan**, **Profil**. Put settings inside Profil. Do not show a persistent offline banner; use a temporary label only when relevant, or show connection status inside Profil.
