# Stitch Prompt — Vocabulary

Use the global Clata prompt. Create the Clata vocabulary screen as a polished, content-first mobile list.

Header: back button, title **Kata**, package context shown once, and a small dictionary icon button in the top-right corner labeled **Buka Kamus**. Do not place search or filters on this screen.

Content: infinite vertical scrollable feed of focused Word Items. Each item shows a large regional-language word such as **Sugeng**, Indonesian meaning **selamat**, word class when useful, a small information icon that opens a very short tooltip for register **Halus**, and a volume icon toggle. The volume icon uses the active brand color while audio is playing. Use a subtle divider and generous vertical spacing.

Show a skeleton at the bottom while the next batch loads. When all items have appeared, loop smoothly to the first item. Show a compact temporary status only when necessary. Do not display destructive actions, search, filters, or a progress bar that implies the user must finish the feed.
