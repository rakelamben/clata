# Stitch Prompt — Challenges

Use the global Clata prompt. Create a challenge screen that feels encouraging and practical rather than competitive.

Header: **Tantangan**, filter controls for **Unit** and **Tingkat**, and a short explanation that challenges do not affect mastery or streak.

Main card: title **Salam pagi pertama**, level badge **Ringan**, goal text, three short Indonesian instruction lines, suggested conversation partner, register badge **Halus**, and a safety note when relevant.

Add a segmented choice **Solo** / **Sosial**. Show a rescue section **Kalau macet** linking to phrases such as **Bisa diulang?**. At the bottom place a large checkbox-style action **Sudah kucoba** with a supportive confirmation state. Do not show correctness scores.
