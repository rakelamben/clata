# Catatan Rilis Clata v1.0.0

Selamat datang di rilis perdana **Clata (Platform Pembelajaran Bahasa Daerah Interaktif)**! Versi `v1.0.0` menghadirkan fondasi aplikasi mobile yang berfokus pada pembelajaran bahasa daerah kontekstual berbasis ragam tutur sosial (*sopan*, *akrab*, *netral*).

---

## 🚀 Fitur Unggulan v1.0.0

### 1. Sistem Onboarding & Pemilihan Paket
- Alur sambutan interaktif yang memperkenalkan pendekatan unik Clata.
- Pemilih paket bahasa lokal (*offline package picker*) yang mendukung instalasi berkas `.clata`.
- Verifikasi tanda tangan digital otomatis (kriptografi Ed25519) untuk menjamin integritas materi.

### 2. Eksplorasi Kosakata (*Vocabulary Feed*)
- Kartu kosakata interaktif dengan indikator visual ragam tutur (*Sopan*, *Akrab*, *Netral*).
- Pemutar audio lokal dengan pengaturan kecepatan putar (*normal* / *lambat*).
- Pencarian dan filter kosakata berdasarkan tema dan unit belajar.

### 3. Sesi Latihan Adaptif (*Practice Sessions*)
- **Tebak Kosakata (*Word Guess*)**: Latihan mengingat arti dan pemakaian kata.
- **Isi Rumpang (*Fill-in-the-Blank*)**: Melatih pemahaman struktur kalimat kanonikal.
- **Percakapan Dua Arah (*Interactive Dialogue*)**: Pohon percakapan dengan lawan bicara virtual dan multi-ending (*pas* / *kurang-pas*) untuk membiasakan etika berbicara.

### 4. Tantangan Dunia Nyata (*Real-World Challenges*)
- Misi aksi praktis (tantangan solo & tantangan sosial) untuk mempraktikkan bahasa di lingkungan sekitar.
- Frasa penyelamat (*rescue phrases*) lengkap dengan audio pendukung.

### 5. Profil & Pelacak Progres Belajar
- Statistik penguasaan kata dan latihan harian.
- Pelacak *streak* belajar harian.
- Manajer paket bahasa terpasang dengan opsi ganti paket aktif atau reset progres.

---

## 📲 Panduan Instalasi APK Android

1. Unduh berkas **`clata-v1.0.0.apk`** dari bagian **Assets** di bawah.
2. Buka berkas `.apk` di perangkat Android Anda.
3. Jika muncul peringatan keamanan *"Instal aplikasi dari sumber tidak dikenal"*, pilih **Izinkan dari sumber ini** / **Setuju**.
4. Selesaikan proses instalasi dan buka aplikasi Clata.

---

## 📦 Memasang Materi Bahasa

Aplikasi Clata didesain modular. Materi bahasa dirilis secara terpisah melalui repositori **`clata-bahasa`**.
1. Unduh paket bahasa yang diinginkan (contoh: `jawa-mataraman.clata`).
2. Di dalam aplikasi Clata, buka menu **Pilih Paket** atau buka tab **Profil > Paket Bahasa**.
3. Klik tombol **Pilih Berkas (.clata)** dan pilih paket yang telah diunduh.
4. Aplikasi akan memverifikasi dan memasang konten secara instan.
