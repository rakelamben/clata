# Architecture Decision Records

ADR mencatat keputusan teknis yang memiliki konsekuensi lintas modul.

## Format

```markdown
# ADR NNNN — Judul

Status: Proposed | Accepted | Superseded | Rejected
Date: YYYY-MM-DD

## Context
## Decision
## Alternatives
## Consequences
## Validation/Evidence
## Supersedes / Superseded by
```

Keputusan yang masih `P` di `docs/decisions.md` tidak boleh diberi status `Accepted` sebelum pemilik produk menyetujuinya. ADR tidak menghapus sejarah keputusan lama.
