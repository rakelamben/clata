# Clata — Google Stitch Visual Prompts

Folder ini berisi deskripsi visual untuk divisualisasikan di Google Stitch. Dokumen ini bukan source code dan bukan pengganti aturan UX/UI di `docs/design/`.

## Cara menggunakan

1. Gunakan `global-prompt.md` sebagai prompt dasar.
2. Tambahkan satu prompt screen dari folder ini.
3. Minta Stitch mempertahankan Bahasa Indonesia, light palette, typography, spacing, radius, motion, dan Remix Icon dari `global-prompt.md`.
4. Visualisasikan satu screen utama terlebih dahulu sebelum membuat variasi state.
5. Simpan hasil visual dan catat perubahan desain sebelum implementasi React Native.
