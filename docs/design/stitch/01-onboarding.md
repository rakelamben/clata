# Stitch Prompt — Onboarding

Use the global Clata prompt. Create a mobile onboarding flow with four lightweight screens. Keep every screen concise and focused.

Screen 1: warm welcome with the title **Belajar bahasa daerah dengan percaya diri**, short explanation **Pelajari kata dan percakapan untuk digunakan sehari-hari**, primary button **Lanjut**, and optional secondary **Lewati**.

Screen 2: title **Siapkan profil lokal**, short copy **Aplikasi berjalan 100% offline. Tahun lahir dan paket belajar disimpan di perangkat**, checkbox konfirmasi penyimpanan data lokal, and primary button **Lanjut**. Do not request login or network.

Screen 3: age selection titled **Berapa tahun lahirmu?**, a clear year-of-birth selector, and primary button **Lanjut**.

Screen 4: package preparation titled **Siapkan paket belajarmu**, short copy **Paket berikut akan dipasang untuk mulai belajar. Semua materi tersedia tanpa koneksi internet**, a package card for the bundled **Jawa – Mataraman** package with content chips and offline status, and a retry state with **Coba lagi**.

Show the local-data warning before entering the app. Keep the layout calm, readable, and usable offline. Avoid login prompts and permission requests.
