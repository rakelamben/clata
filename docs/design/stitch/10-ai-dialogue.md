# Stitch Prompt — AI Dialogue

Use the global Clata prompt. Design an AI dialogue screen that visually shares the same renderer as curated dialogue but clearly labels AI origin.

Entry state: heading **Dialog AI**, label **Untuk pengguna 10+**, concise account/guardian-consent requirement, online requirement, and quota indicator **Sisa 2 dari 3 sesi hari ini**. Primary button **Mulai dialog AI**.

Generated state: show a prominent but calm label **Dibuat AI, belum diverifikasi penutur**, conversation lines, target words, and explicit **Tanpa audio** marker on AI lines. Existing bank words may have volume-icon toggles with active brand color while playing. Do not show Gemini or Groq provider names in the user interface.

Failure states: offline, quota exhausted, provider fallback, generation retry, validation failed, and fallback card **Gunakan dialog kurasi**. Include a compact action **Laporkan kalimat ini**. Avoid chat bubbles that imply unrestricted free chat.
