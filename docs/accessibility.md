# Clata Accessibility Standard

Target: WCAG 2.2 AA principles adapted to React Native.

- Text MUST remain usable at 200% font scale without clipping or loss of action.
- Interactive targets SHOULD be at least 44x44 points.
- Every audio control needs an accessible label, state, and replay action.
- Do not communicate meaning by color alone.
- Focus order and screen-reader names must follow the visual reading order.
- Loading, errors, offline state, and success state must be announced where appropriate.
- Dialog choices must expose the full text and selected state to assistive technology.
- Animations SHOULD respect reduced-motion preferences.
- Test TalkBack and VoiceOver on small screens and enlarged text before release.
