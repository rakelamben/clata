# Stitch Prompt — Curated Dialogue

Use the global Clata prompt. Design a visual-novel-like but accessible curated dialogue screen.

Header: title **Di warung**, unit label, progress through the dialogue, and a translation toggle labeled **Tampilkan terjemahan**.

Main area: a calm conversation transcript with speaker name, regional-language line, Indonesian translation, and individual volume-icon toggles. Use speech bubbles sparingly; prioritize readable transcript flow. A playing volume icon uses the active brand color; stop then play starts from the beginning.

At a choice point, show heading **Pilih cara bicara**, then three large choice cards. Each card contains the regional phrase. Show **Pas**, **Cukup pas**, or **Kurang pas** only when needed for feedback; avoid repeated badges. Include a visible **Ucapkan sendiri** action that can be skipped and never requests microphone permission.

Show an alternate repair state for an unrelated answer: a gentle response from the character, one short explanation, and the same choices again. End with simple feedback such as **Pas** or **Coba cara lain**, not a score punishment.
