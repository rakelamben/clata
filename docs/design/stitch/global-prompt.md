# Global Google Stitch Prompt

Design a polished mobile learning app called **Clata — Celoteh Nusantara** for Android and iOS.

Clata helps Indonesian young people learn regional languages offline so they can speak warmly with family and local communities. The current content package is Javanese, Mataraman dialect. The system interface language is always Bahasa Indonesia.

## Visual direction

Use the Clata light editorial learning aesthetic: neutral white/off-white surfaces, dark navy ink, burnt orange primary actions, restrained magenta attention accents, teal progress accents, generous whitespace, Gloock display typography, Public Sans body text, Lexend UI labels, subtle paper/card texture, and restrained rounded surfaces. The result should feel friendly, grounded, culturally respectful, and modern—not folkloric, childish, gamified, or generic SaaS.

## Design tokens

- Background: neutral `#FAFAFA`
- Surface: white `#FFFFFF`
- Primary ink: navy `#0A2E44`
- Primary text: `#111111`
- Muted text: `#4A4A4A`
- Primary action: burnt orange `#AD3603`
- Pressed primary/focus: navy `#0A2E44`
- Attention/error: magenta `#960238`
- Success/progress: teal `#166868`
- Warning: `#8A5200`
- Border: `#D9D9D9`
- Spacing rhythm: 4, 8, 12, 16, 24, 32, 40 dp
- Radius: control 10 dp, card 12 dp, sheet 16 dp
- Motion: fast 120 ms, standard 200 ms, emphasis 280 ms, slow 360 ms
- Body text starts at 16sp
- Touch targets: at least 44×44 pt iOS or 48×48 dp Android
- Icon library: Remix Icon only; no emoji or mixed icon families

## Product rules

- One primary action per screen.
- Use Indonesian labels and actions.
- Use vector icons, never emoji as structural icons.
- Audio controls are prominent but never autoplay.
- Do not use color alone to show correctness or status.
- Include realistic loading, empty, error, offline, disabled, and success states.
- Design for screen readers, 200% font scale, safe areas, and reduced motion.
- Keep the interface usable in airplane mode.

Create a high-fidelity mobile screen with a clear hierarchy, realistic Indonesian copy, accessible controls, and production-ready spacing. Do not create a desktop layout.
