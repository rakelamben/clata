# Screen: Pengingat

## Layout

Diakses melalui `Profil → Pengaturan → Pengingat`. Tampilkan status pengingat, time picker, hari aktif, dan copy `Pengingat bersifat opsional.` Permission OS diminta hanya setelah pengguna mengaktifkan toggle.

## States

`disabled`, `permission required`, `enabled`, `permission denied`, `invalid time`, dan `saved`.

## Accessibility

Toggle, time picker, dan day selector memiliki label serta state tekstual. Jika permission ditolak, tampilkan alasan dan action `Buka pengaturan perangkat`; jangan meminta permission berulang tanpa tindakan pengguna.
