# Screen: Tentang Clata

## Layout

Diakses melalui `Profil → Pengaturan → Tentang Clata`. Tampilkan logo resmi, versi aplikasi, lisensi, privacy link, open-source notices, package credits, dan kontak laporan masalah.

Logo dekoratif hidden dari accessibility tree bila nama Clata sudah menjadi heading. Semua link memiliki tujuan yang deskriptif dan dapat dibuka offline bila dokumennya tersedia lokal.
