# Flow: Challenges

`Tantangan → filter unit/level → open challenge → choose Solo/Sosial → read safety/instructions → try externally → self-check Sudah kucoba`.

- Challenge has no correctness score and creates no learning event.
- Social variant never assumes a second person can speak the language.
- Safety guidance is visible for minors.
- If stuck, rescue phrases link to Unit 1 content.
- Completed check remains local and does not affect streak, mastery, statistics, or sync.
