# Clata Glossary

- **Package**: seluruh konten satu kombinasi bahasa-dialek.
- **Language**: pengelompokan bahasa untuk tampilan.
- **Dialect**: ruang konten mandiri; tidak mewarisi item dialek lain.
- **Register**: tingkat tutur yang menjadi tag konten.
- **Item**: kata, kalimat, dialog, atau challenge ber-ID stabil.
- **Viewed**: tampil minimal satu detik atau muncul sebagai target dialog sesuai PRD.
- **Learning event**: catatan append-only aktivitas belajar.
- **Strength**: kekuatan item 0..1 yang diturunkan dari event.
- **Mastery**: skor komposit kosakata, kalimat, dan dialog.
- **Active day**: tanggal lokal dengan minimal sepuluh kata unik dilihat.
- **Derived cache**: data yang dapat dibangun ulang dari source data.
- **Tombstone**: penanda command/reset agar data lama tidak muncul lagi saat merge.
- **Atomic install**: paket baru aktif seluruhnya atau tidak aktif sama sekali.
